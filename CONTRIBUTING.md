# Contributing

Thanks for helping with paperless-pwa-share. Keep the app small: no frameworks, no UI libraries, as little code as reasonable.

1. `npm ci`
2. `npm run typecheck && npm test && npm run build` must pass (CI runs the same).
3. Open a pull request against `main`.

By contributing you agree to license your contribution under `Unlicense OR 0BSD`, like the rest of the project.
